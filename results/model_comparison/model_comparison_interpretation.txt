MODEL COMPARISON INTERPRETATION
================================================================================

Compared models:
  1. GP pair: independent GP models for peak_y and max_abs_xr.
  2. NN multi-output: one PyTorch MLP predicting [peak_y, max_abs_xr].

Main accuracy comparison:
  peak_y RMSE: GP pair = 13.15 mm, NN = 15.50 mm.
  max_abs_xr RMSE: GP pair = 3.97 mm, NN = 4.39 mm.
  False feasible rate: GP pair = 0.50%, NN = 1.00%.
  Near-boundary RMSE: GP pair = 1.96 mm, NN = 2.41 mm.

Interpretation: with the current dataset size, the GP pair provides better predictive accuracy than the NN multi-output surrogate. This is consistent with Gaussian Processes being data-efficient for small to medium-sized datasets.

The NN remains useful because it is differentiable in PyTorch and can be used directly for gradient-based inverse optimization. The GP pair remains the more conservative choice for constraint-aware optimization when accuracy and low false-feasible rate are prioritized.

Inference-time comparison:
  batch=1: GP pair = 411.540 µs/sample; NN multi-output = 325.600 µs/sample
  batch=1000: GP pair = 124.627 µs/sample; NN multi-output = 0.857 µs/sample
  batch=10000: GP pair = 115.746 µs/sample; NN multi-output = 0.535 µs/sample
