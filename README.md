# ML-Based Inverse Optimization for Extra-Reach Planning of a Compliant-Base Robot

Machine Learning framework for **constraint-aware extra-reach planning** of a robot mounted on a compliant passive base.

The goal is to exploit the base dynamics to extend the effective end-effector reach beyond the robot's nominal workspace, while keeping the actuated robot motion within its physical limits.

The project combines:

- Physics-based dynamic simulation
- Simulation-driven dataset generation
- Gaussian Process and Neural Network surrogate modeling
- Constrained inverse optimization
- True-simulator validation
- Sensitivity and robustness analysis

Developed as a final project for the **Machine Learning for Mechanical Systems** course at **Politecnico di Milano**.

---

## Overview

The system consists of a robot mounted on a compliant passive base.

The total horizontal end-effector outreach is defined as:

$$
y(t) = x_b(t) + x_r(t)
$$

where:

- $x_b(t)$ is the compliant-base displacement
- $x_r(t)$ is the robot displacement relative to the base

The robot itself is constrained by:

$$
\max_t |x_r(t)| \leq 0.500 \text{ m}
$$

The objective is therefore not to move the robot beyond its allowed workspace, but to exploit the passive motion of the compliant base to obtain additional reach.

The inverse-planning problem consists of finding excitation and impedance parameters that achieve a desired target outreach while respecting the workspace constraint.

---

## System Model

The compliant-base robot is modeled as a simplified **two-degree-of-freedom mass-spring-damper system**.

The robot is excited using a chirp-like reference trajectory, while the interaction between the robot and the compliant base generates additional dynamic displacement.

The controllable parameters used during inverse optimization are:

```text
Kr
hr
f0
f1
A
x_r_start
```

These parameters describe the robot impedance and excitation profile.

The physical base parameters are fixed during the final inverse-planning experiments:

```text
Kb = 1000
Mb = 20
hb = 0.10
Mr = 10
```

The main simulated outputs are:

```text
peak_y       Maximum absolute end-effector outreach
max_abs_xr   Maximum robot displacement relative to the base
```

A solution is considered feasible only if:

```text
max_abs_xr <= 0.500 m
```

---

## Dataset Generation

The Machine Learning surrogate models are trained entirely on data generated by the physics-based simulator.

Each simulation maps a set of physical and excitation parameters to:

- Achieved peak outreach
- Maximum robot relative displacement
- Workspace feasibility

The dataset generation process combines:

1. Broad sampling of the complete parameter space
2. Targeted augmentation around high-outreach feasible regions

The second stage increases the number of informative samples close to the physical workspace boundary, where the inverse-optimization problem is most challenging.

---

## Surrogate Models

Two different surrogate-model families are investigated.

### Gaussian Processes

Two independent Gaussian Process regressors are trained to estimate:

```text
parameters -> peak_y
parameters -> max_abs_xr
```

Gaussian Processes provide both:

- Predicted mean
- Predictive uncertainty

This uncertainty is exploited during optimization to discourage solutions in poorly modeled regions.

### Neural Network

A multi-output feed-forward Neural Network predicts both quantities simultaneously:

```text
parameters -> [peak_y, max_abs_xr]
```

The Neural Network is implemented in **PyTorch** and is specifically designed to remain differentiable with respect to its input parameters.

This allows the surrogate itself to be used inside a gradient-based inverse-optimization procedure.

---

## Inverse Optimization

Four optimization strategies are compared.

### GP + Differential Evolution

```text
Gaussian Process surrogate
        +
Differential Evolution
```

A global, population-based optimizer searches the parameter space using the GP predictions.

Predictive uncertainty is incorporated into the objective to obtain a conservative solution near the workspace boundary.

### Neural Network + Adam

```text
Neural Network surrogate
        +
Multi-start Adam optimization
```

The differentiability of the PyTorch surrogate allows gradients to be propagated directly with respect to the input design variables.

Multiple initial solutions are optimized in parallel, and the best candidates are subsequently validated using the original physics-based simulator.

### Bayesian Optimization

Bayesian Optimization directly queries the true simulator during the optimization process.

Unlike the previous approaches, it does not rely on the offline surrogate dataset.

### Random Search

Random Search is included as an unguided baseline using a comparable simulation budget.

---

## Main Results

All final optimization methods were able to identify feasible solutions for the tested targets.

Among the surrogate-based approaches, **NN + Adam** provided the best overall accuracy-runtime compromise.

Its final performance was approximately:

```text
Mean target error:       20.4 mm
Feasibility rate:        100%
Minimum residual margin: 3 mm
Total optimization time: ~7 s
```

The larger overall mean error is mainly caused by target values beyond the physical reach of the constrained system.

For dynamically reachable targets, the tracking error is significantly smaller.

---

## Representative Reachable Solution

For a desired outreach of:

```text
Target = 0.650 m
```

the **NN + Adam** approach obtained:

```text
Achieved outreach:       ~0.650 m
Tracking error:          ~0.3 mm
Maximum robot motion:    ~0.490 m
Extra reach:             ~150 mm
```

The robot remains within its nominal **0.500 m workspace**, while the compliant-base displacement provides the additional reach required to achieve the target.

This demonstrates that the extra reach is generated by the system dynamics rather than by violating the robot workspace constraint.

---

## Saturated High-Outreach Solution

For the more aggressive target:

```text
Target = 0.750 m
```

the optimized solution reached approximately:

```text
Achieved outreach:       ~0.674 m
Tracking error:          ~75.7 mm
Maximum robot motion:    ~0.497 m
```

The optimizer does not force the robot beyond its allowed workspace.

Instead, the solution saturates close to the maximum physically achievable outreach of the compliant system.

This highlights an important distinction between:

- Optimization failure
- Physical infeasibility of the requested target

## Sensitivity and Robustness

Nominal feasibility alone does not guarantee that an optimized solution remains safe when the physical model changes.

For this reason, the final solutions are also evaluated through sensitivity and robustness analyses.

### One-at-a-Time Sensitivity Analysis

Individual system and control parameters are perturbed independently to identify the variables with the largest influence on:

- Peak outreach
- Workspace margin
- Solution feasibility

### Monte Carlo Robustness Analysis

Multiple physical parameters are perturbed simultaneously to evaluate the effect of model uncertainty.

The analysis shows that moderate extra-reach targets remain significantly more robust than solutions operating very close to the maximum workspace boundary.

This highlights the importance of conservative margins when transferring optimized trajectories toward real robotic systems.

## Summary

This repository implements a complete **simulation-to-optimization Machine Learning pipeline** for extra-reach planning of a compliant-base robot.

Physics-based simulations are used to generate training data for Gaussian Process and Neural Network surrogate models, which are subsequently integrated into constraint-aware inverse-optimization algorithms.

The results demonstrate that passive compliant-base dynamics can be exploited to extend the effective robot reach beyond its nominal workspace while maintaining the actuated robot motion within its physical constraint.

The project also highlights the importance of surrogate accuracy, conservative constraint handling, and robustness analysis when Machine Learning models are used for the optimization of physical robotic systems.
